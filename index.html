★ Producto estrella · En producción

TrackAI — Copiloto de mezcla con IA para DJs

Sistema de inteligencia musical en tiempo real para Serato DJ Pro. Lee en vivo la base master.sqlite cada 3 s (sin API pública) y sugiere la siguiente canción con un motor de recomendación multicapa sobre un espacio vectorial de firma armónica (Camelot), BPM, energía y género.

  • Base de datos vectorial: cada track se modela como vector armónico; las sugerencias se calculan por similitud, no por reglas fijas.
  • Motor armónico Camelot: transiciones por misma llave, escalas vecinas y saltos de energía calculados.
  • Live Pitch®: detección de BPM con pitch aplicado, tendencia del set y zonas de mezcla adaptativas.
  • Cerebro que aprende: memoria de transiciones personal y global con decay temporal, cold start y score de confianza.
  • Licenciamiento criptográfico: tokens Ed25519 firmados, activación por key + device, revalidación en vivo y upgrade LITE → PRO automático.
  • Seguridad: rate limiting, comparación timing-safe y anti-replay en webhooks.
  • Multiplataforma: macOS (arm64) y Windows 10/11 desde un solo código base.
