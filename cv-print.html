Proyectos destacados

TrackAI — Copiloto de mezcla con IA para DJs2026 · Producción

Sistema de inteligencia musical en tiempo real para Serato DJ Pro. Lee en vivo la base master.sqlite cada 3 segundos, sin API pública, y sugiere la siguiente canción mediante un motor de recomendación multicapa.

  • Base de datos vectorial: cada track se modela por firma armónica (Camelot), BPM, energía y género; las sugerencias se calculan por similitud vectorial.
  • Motor armónico Camelot: transiciones por misma llave, escalas vecinas y saltos de energía calculados.
  • Live Pitch®: detección de BPM con pitch aplicado, tendencia del set y zonas de mezcla adaptativas.
  • Cerebro que aprende: memoria de transiciones personal y global con decay temporal, cold start y score de confianza.
  • Licenciamiento criptográfico: tokens Ed25519 firmados, activación por key y device, revalidación en vivo, upgrade LITE a PRO automático.
  • Seguridad: rate limiting, comparación timing-safe y protección anti-replay en webhooks.

Stack: Electron 31 · JavaScript · PostgreSQL (Neon) · SQLite · Cloudflare Workers · Ed25519
