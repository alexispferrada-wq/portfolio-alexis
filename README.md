## 🚀 Proyectos Insignia en Producción

### 1. 🎚️ [TrackAI](https://trackai.party) — Copiloto de Mezcla con IA para DJs
- **Web Oficial:** [https://trackai.party](https://trackai.party)
- **Manual de Cabina:** [https://trackai.party/ayuda](https://trackai.party/ayuda)
- **Librería Open Source:** [@alexispferrada-wq/trackai-lib](https://github.com/alexispferrada-wq/trackai-lib)
- **Innovación:** Lectura sin API de `master.sqlite` de Serato DJ Pro cada 3 s, espacio vectorial armónico Camelot, algoritmo **Live Pitch®** con compensación de pitch en vivo, memoria de transiciones con aprendizaje continuo y tokens de licenciamiento Ed25519 con verificación en Cloudflare Workers.

### 2. 💾 [PRE-SET by TrackAI](https://preset.trackai.party) — Arquitectura Dataless 0 KB para macOS
- **Web Oficial:** [https://preset.trackai.party](https://preset.trackai.party)
- **Innovación:** Solución al límite de espacio en disco en Apple Silicon (M1 a M4). Estructuración de crates de Serato a 0 KB mediante enlaces APFS y clones virtuales, sincronización selectiva con Google Drive, streaming bajo demanda con HTTP Range (206) y detección automática de hardware externo USB-C.

### 3. 🤖 [Siti.work / TuSitioLabs](https://siti.work) — Infraestructura de Agentes IA
- Plataforma SaaS multitenant de agentes autónomos con RAG, embeddings vectoriales y function calling ejecutándose sobre Docker, Caddy, Evolution API y Cloudflare Workers.

### 4. 🛒 [TurboPOS](https://turbopos.cl) — Punto de Venta SaaS
- SaaS comercial multitenant para almacenes y pymes con arquitectura Django + PostgreSQL (Neon), HTMX y autenticación ágil por PIN/QR.
